# DELTARUNE.exe — Reverse Engineering Analysis

Analysis of `DELTARUNE.exe`, the native executable shipped with DELTARUNE (Steam).
This binary is **not** custom game code — it is the **GameMaker Studio 2 "VC_Runner"
runtime** (the YoYo Games virtual-machine interpreter). The actual game lives in the
companion `data.win` file, which this runner loads and interprets. Reverse-engineering
this binary therefore documents the **GameMaker runtime engine**, not DELTARUNE's plot
logic.

## What this analysis accomplished

1. **Identified the runtime** as the GameMaker VC_Runner and mapped its core value model.
2. **Defined the `RValue` type system** in the IDB (struct + 16-value `RValueKind` enum).
3. **Auto-named 1,876 GML built-in functions** (`gml_*`) by statically tracing every
   `Function_Add(name, func, argc)` registration call (2,514 call sites, 0 failures).
   This converted ~9% of all functions — and the overwhelming majority of *semantically
   meaningful* ones — from `sub_xxxxxxxx` into readable names.
4. **Analyzed and renamed the core runtime primitives**: the `YYGet*` argument
   accessors, RValue coercion/free/serialization, the function-registration table, and
   the error/exception reporter.
5. **Documented the data-structure (`ds_*`) subsystem** internals.

## Key facts at a glance

- **`RValue`** is the universal 16-byte tagged value: 8-byte payload (union of
  `double`/`void*`/`int`/`int64`), a 4-byte `flags` word at +8, and a 4-byte `kind`
  tag at +12 (only the low 24 bits are the type).
- **Built-ins are registered**, not hard-dispatched: `Function_Add` appends
  `{const char* name, void* func, int argc}` (24-byte) entries to a global table. A
  GML built-in is a C function `void f(RValue* result, void* self, void* other,
  int argc, RValue* args)`; `argc == -1` marks a variadic builtin (46 of them).
- The runtime statically links **GGPO** (rollback netcode — 18 `rollback_*` builtins +
  the `GGPO_Log` logger), **WININET/WS2_32** (HTTP + sockets), **Media Foundation**
  (video playback), **D3D11**, **GDI+**, and **Steamworks-adjacent** plumbing.
